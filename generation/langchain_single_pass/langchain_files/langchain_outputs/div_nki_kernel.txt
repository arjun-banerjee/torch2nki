```python
from neuronxcc import nki
import neuronxcc.nki.language as nl

@nki.jit
def nki_div(a_tensor, b_tensor):
    # Ensure tensors have the same shape
    if a_tensor.shape != b_tensor.shape:
        raise ValueError("Tensors must have the same shape")
    
    # Initialize result tensor in shared HBM
    result = nl.ndarray(a_tensor.shape, dtype=a_tensor.dtype, buffer=nl.shared_hbm)
    
    # Load tensors into on-chip memory (SBUF)
    a_tile = nl.load(a_tensor)
    b_tile = nl.load(b_tensor)
    
    # Perform element-wise division
    temp_result = nl.divide(a_tile, b_tile)
    
    # Store result back to HBM
    nl.store(result, temp_result)
    
    return result
```

This implementation:

1. Takes two input tensors (a_tensor and b_tensor)
2. Verifies they have the same shape
3. Initializes a result tensor in shared HBM with the same shape and dtype as the input
4. Loads both input tensors from HBM into SBUF
5. Performs element-wise division using nl.divide
6. Stores the result back to HBM
7. Returns the result tensor

The kernel follows best practices by:
- Using proper error checking
- Following the NKI memory hierarchy (HBM → SBUF → computation → HBM)
- Using the appropriate NKI operations (load, divide, store)
- Properly initializing the result tensor
- Following the required pattern of using a temporary variable for computation and storing to result

Note that this implementation assumes the input tensors fit within the available SBUF memory. For larger tensors, you would need to implement tiling logic using affine_range.
