```python
from neuronxcc import nki
import neuronxcc.nki.language as nl

@nki.jit
def nki_sqrt(a_tensor):
    # Initialize result tensor with same shape and dtype as input
    result = nl.ndarray(a_tensor.shape, dtype=a_tensor.dtype, buffer=nl.shared_hbm)
    
    # Load input data from HBM to on-chip memory
    in_tile = nl.load(a_tensor)
    
    # Compute square root
    temp = nl.sqrt(in_tile)
    
    # Store result back to HBM
    nl.store(result, value=temp)
    
    return result
```

This implementation:

1. Takes an input tensor `a_tensor`
2. Creates a result tensor with the same shape and dtype as the input
3. Loads the input data from HBM to on-chip memory
4. Computes the square root using the built-in `nl.sqrt()` function
5. Stores the result back to HBM
6. Returns the result tensor

Key features:
- Uses proper NKI memory hierarchy (HBM to on-chip memory and back)
- Utilizes the built-in sqrt function from the NKI language module
- Handles data types properly through inheritance from input tensor
- Follows the required pattern of initializing result, computing via temporary variable, storing to result, and returning result

The kernel will work efficiently by:
- Minimizing memory transfers
- Using hardware-optimized sqrt implementation
- Maintaining proper data locality
- Following NKI best practices for memory management
